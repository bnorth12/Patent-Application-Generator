# Releases

This folder contains immutable, signed release candidate builds and documentation. Each subfolder is a distinct release, copied from development folders at the time of release gate approval.

- No development or test artifacts should be modified here after release.
- Each release must include:
  - Source code snapshot
  - Verification test results
  - Governance and planning artifacts as of release
  - Release notes and GO/NO-GO evidence

Use this folder to support audits, rollbacks, and compliance reviews.
