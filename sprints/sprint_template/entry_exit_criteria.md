# Sprint NN – Entry and Exit Criteria

**Sprint Number**: NN  
**Sprint Branch**: `sprint/sprint-NN`

---

## Entry Criteria

All of the following must be true before the sprint branch is created and work begins:

- [ ] Sprint plan document completed (`sprint_plan.md`)
- [ ] Sprint requirements document completed (`requirements.md`)
- [ ] Sprint stories document completed (`stories.md`)
- [ ] All sprint stories in "Ready" state (acceptance criteria defined, points estimated)
- [ ] All backlog items for this sprint have GitHub issues created
- [ ] Sprint branch created: `sprint/sprint-NN`
- [ ] Previous sprint closed (or this is Sprint 1)
- [ ] Governance tests passing on `main`

---

## Exit Criteria

All of the following must be true before the sprint-close PR is merged:

- [ ] All sprint stories are in "Done" state
- [ ] All sprint requirements verified against acceptance criteria
- [ ] All new code has unit tests with ≥ 80% coverage
- [ ] All governance tests passing on the sprint branch
- [ ] All CI checks passing on the sprint branch
- [ ] No open Critical or High severity bugs
- [ ] Sprint retrospective notes added to `sprint_plan.md`
- [ ] Sprint-close PR created from `sprint/sprint-NN` → `main`
- [ ] Sprint-close PR references and closes all sprint GitHub issues
- [ ] Sprint-close PR reviewed and approved
